# NLP_PROJECT

## 프로젝트 소개

이 저장소는 자연어 처리(NLP) 프로젝트를 위한 저장소입니다. 텍스트 데이터를 수집하거나 불러온 뒤 전처리, 모델 학습, 평가 과정을 수행하는 코드를 관리합니다.

## 사용한 데이터셋

본 프로젝트에서 사용하는 데이터셋 정보는 아래와 같습니다.

| 항목 | 내용 |
| --- | --- |
| 데이터셋 이름 | 추후 작성 |
| 데이터 출처 | 추후 작성 |
| 데이터 형식 | 추후 작성 |
| 주요 컬럼 | 추후 작성 |
| 사용 목적 | 자연어 처리 모델 학습 및 평가 |

데이터셋은 용량이나 저작권 문제로 인해 저장소에 직접 포함하지 않을 수 있습니다. 이 경우 데이터셋을 내려받은 뒤 프로젝트 루트 또는 별도의 `data/` 폴더에 배치하여 사용합니다.

예시 구조는 다음과 같습니다.

```text
NLP_PROJECT/
├── data/
│   └── dataset 파일
├── README.md
└── 소스 코드 파일
```

## 코드 소개

이 프로젝트의 코드는 자연어 처리 실험 과정을 단계별로 구성하는 것을 목표로 합니다.

| 구분 | 설명 |
| --- | --- |
| 데이터 로드 | 데이터셋을 불러오고 학습에 필요한 형태로 변환합니다. |
| 전처리 | 결측치 제거, 텍스트 정제, 토큰화 등 NLP 전처리를 수행합니다. |
| 모델 학습 | 전처리된 데이터를 이용해 자연어 처리 모델을 학습합니다. |
| 모델 평가 | 정확도, F1-score 등 평가 지표를 사용해 모델 성능을 확인합니다. |
| 결과 저장 | 실험 결과나 모델 출력값을 저장합니다. |

현재 저장소에는 기본 README 파일만 포함되어 있으며, 이후 프로젝트 코드가 추가되면 각 파일의 역할을 이 항목에 정리합니다.

## 설치 안내

프로젝트를 실행하기 위해 먼저 저장소를 클론합니다.

```bash
git clone https://github.com/timjin06/NLP_PROJECY.git
cd NLP_PROJECY
```

Python 가상환경 생성을 권장합니다.

```bash
python -m venv .venv
```

Windows PowerShell에서는 다음 명령어로 가상환경을 활성화합니다.

```bash
.venv\Scripts\Activate.ps1
```

필요한 패키지는 프로젝트에 `requirements.txt`가 추가된 뒤 다음 명령어로 설치합니다.

```bash
pip install -r requirements.txt
```

아직 `requirements.txt`가 없다면, 사용하는 라이브러리를 설치한 뒤 아래 명령어로 의존성 파일을 생성할 수 있습니다.

```bash
pip freeze > requirements.txt
```

## 실행 방법

프로젝트 코드가 추가된 뒤에는 다음과 같은 방식으로 실행합니다.

```bash
python main.py
```

실행 파일명이 다를 경우 실제 코드 파일명에 맞게 명령어를 수정합니다.

## 브랜치 안내

이 저장소는 다음 브랜치를 사용합니다.

| 브랜치 | 설명 |
| --- | --- |
| `step1` | 기본 브랜치 |
| `step2` | 2단계 작업 브랜치 |
| `step3` | 3단계 작업 브랜치 |
| `test_date` | 테스트용 브랜치 |

README 파일은 브랜치별로 여러 개 만들지 않고, 프로젝트 안내용 `README.md` 파일 하나만 관리합니다.
